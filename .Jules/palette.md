## 2026-01-XX - [Accessibility] Skip to Main Content Link
**Learning:** Adding a "Skip to Main Content" link is a high-impact, low-effort accessibility improvement that drastically improves navigation for keyboard and screen reader users. It's often overlooked but essential for WCAG compliance.
**Action:** Always check for a skip link in the root layout (`default.html` or similar) and ensure the target ID exists on the main content container.
