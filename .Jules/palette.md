## 2026-01-20 - Focus Visible & Accessibility
**Learning:** Standard outline styles often get suppressed by modern CSS resets or user preference, making keyboard navigation difficult. The `:focus-visible` pseudo-class is the modern, robust way to show focus rings only when needed (keyboard navigation) without annoying mouse users.
**Action:** Always include a global `:focus-visible` rule in the base stylesheet of any project to ensure baseline accessibility.
