## 2026-01-XX - [Added Focus Visible States]
**Learning:** The site lacked visible focus indicators for keyboard navigation, making it difficult for users to navigate without a mouse.
**Action:** Implemented `:focus-visible` styles using `outline` and `box-shadow` for buttons to ensure clear visual feedback for keyboard users while maintaining the design aesthetic for mouse users. Also added `scroll-behavior: smooth` and `prefers-reduced-motion` support.
